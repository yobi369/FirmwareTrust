# Security Policy

Do not publish exploitable vulnerability details in a public issue. Until a dedicated security contact is established, report suspected vulnerabilities privately through GitHub's repository security advisory mechanism.

Include the affected version or commit, impact, reproduction steps and suggested mitigation. Do not include secrets or private signing keys.

This is an early-development prototype with no production releases or security support guarantees. Do not use it as the sole security control for production or safety-critical devices.
